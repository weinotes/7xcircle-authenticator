# Code of Conduct

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1.

## Our standard

Be direct and kind. This app holds other people's account keys, so the same
discipline applies in review: criticise the code, never the person, and do not
shrug off a correctness or security concern because it is inconvenient.

Specifically:

- Assume good faith; ask before assuming someone is wrong.
- Feedback on a PR applies to the code, not the author.
- No harassment, personal attacks, or gatekeeping based on experience level.
- Security reports are handled privately first, then disclosed with a timeline.
- Maintain the project's scope: this is an offline authenticator, not a platform.

## Reporting

Email **support@7xcircle.com** with `Code of Conduct` in the subject. Reports are
reviewed by the maintainer; if the report concerns the maintainer, state that and
it will be handled by a contributor you name.

## Enforcement

1. **Private warning** for a first, minor lapse.
2. **Public clarification** if the behaviour repeats or happened in public.
3. **Temporary ban** from the repository for sustained or serious violations.
4. **Permanent ban** where trust cannot be restored.
