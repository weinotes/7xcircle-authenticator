7X Circle 验证器

7X Circle Authenticator

面向 7X Circle 会员的离线双因素验证器。TOTP / HOTP 令牌全部在本机计算， 应用不发起任何网络请求，也不需要账号。

当前版本 v1.4.0 Android 8.0+ 正式签名 Apache-2.0 开源
下载 Android 版app-release.apk · 54.7 MiB 国内镜像下载Gitee · 大陆访问更快

安装时若提示「未知来源应用」，请在系统设置中允许当前浏览器或文件管理器安装。

安装步骤

  1. 点上面的按钮下载 app-release.apk（约 54.7 MiB，正式签名版）。
  2. 打开下载好的文件；系统提示「出于安全考虑，禁止安装未知应用」时，选择允许本次安装。
  3. 安装完成后打开应用，扫描 7X Circle 下发的 otpauth:// 二维码，或手动输入密钥添加令牌。
  4. 建议进入「设置 → 应用锁」开启 PIN：开启后令牌密钥以 AES-256-GCM 加密存储。

忘记 PIN 无法找回，只能用开启应用锁之前导出的加密备份恢复，请务必先备份。

校验你下载的文件

Release 页面上的 app-release.apk 标注了 SHA-256。下载后可本地复算比对， 两者一致说明文件与发布时完全相同。

487604fee76984dc8a6be8717e598964e4554c740df8e2228ff592cc3df53f23

macOS：shasum -a 256 app-release.apk　·　Linux：sha256sum app-release.apk

安全与隐私

  • 不联网：应用代码不含网络请求，由仓库内测试自动断言。
  • 无账号、无埋点、无云端同步；令牌只存在本机。
  • 可选应用锁：PIN 经 PBKDF2-SHA256 派生，令牌以 AES-256-GCM 加密。
  • 已关闭 Android 自动备份，避免备份带走密钥。

English

7X Circle Authenticator is an offline TOTP/HOTP two-factor client for the 7X Circle club. Tokens are generated on-device, the app performs no network requests and needs no account. The Android APK above is debug-free, signed with the project release key and requires Android 8.0+. Verify the SHA-256 above against the file you downloaded.
